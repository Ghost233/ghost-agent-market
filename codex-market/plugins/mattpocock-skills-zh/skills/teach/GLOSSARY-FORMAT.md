# GLOSSARY.md 格式

`GLOSSARY.md` 是此教学工作区的规范语言。所有讲解、练习和学习记录都必须遵循其中的术语。构建术语表本身也是学习的一部分：能把概念压缩为严谨定义，说明用户已经理解它。

## 结构

```md
# {主题}术语表

{用一两句话说明此术语表覆盖的主题。}

## 术语

**肌肥大**：
在重复训练中，由机械张力和代谢压力驱动的肌肉增长。
_避免使用_：增肌、练大块

**渐进超负荷**：
随时间推移，通过负重、训练量或强度系统性提高肌肉承受的要求。
_避免使用_：更用力、升级

**RPE（主观用力程度）**：
以 1–10 对一组动作的费力程度进行自评，其中 10 表示力竭，8 表示还能完成两次重复。
_避免使用_：用力分数、强度评分
```

## 规则

- **只在用户理解术语后才添加。** 术语表是压缩知识的记录，不是供用户初次学习的字典。如果用户刚接触某个概念，等到他们能够正确使用后再收入术语表。
- **明确作出取舍。** 同一概念有多种说法时，选定最好的一个，并把其余写成应避免的别名。语言由此得到压缩。
- **保持定义严谨简短。** 限一两句话。定义术语_是什么_，而不是它做什么或怎样操作。
- **在定义中使用术语表已有术语。** 术语一旦进入术语表，就在所有地方优先使用，包括其他定义内部。这会让复杂术语以后更容易理解。
- 自然形成类别时，**用子标题分组**（如 `## 解剖学`、`## 训练设计`）。术语本身紧密相关时，扁平列表也可以。
- **明确标注歧义。** 如果某术语在领域中使用宽泛，要写明本工作区的约定：“在此工作区，‘组’始终指正式训练组，热身组另行记录。”
- **随理解深入而修订。** 用户第一周写下的定义到第六周可能已经错误。就地更新，不要保留过时条目。
