---
name: resolving-merge-conflicts
description: "用于解决正在进行的 Git merge 或 rebase 冲突。"
---

1. **查看当前状态。** 检查 merge/rebase 的状态、Git 历史以及冲突文件。

2. **为每处冲突找到一手来源。** 深入理解双方为什么作出各自的修改，以及原始意图是什么。阅读 commit 消息、PR 和最初的 issue/工单。

3. **逐个解决冲突块。** 尽可能保留双方意图；如果意图互不兼容，选择符合本次合并既定目标的一方，并记录取舍。**不要**发明新行为。始终解决冲突，绝不使用 `--abort`。

4. 找出并运行项目的**自动化检查**，通常依次为类型检查、测试和格式化。修复此次合并破坏的所有内容。

5. **完成 merge/rebase。** 暂存所有文件并提交。如果正在 rebase，则继续该流程，直到所有 commit 都完成变基。
