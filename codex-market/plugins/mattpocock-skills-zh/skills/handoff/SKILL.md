---
name: handoff
description: 将当前对话压缩为交接文档，供另一个代理继续处理。仅在用户明确调用时使用。
---

编写一份总结当前对话的交接文档，让新的代理能够继续工作。将它保存到用户操作系统的临时目录，不要保存到当前工作区。

在文档中加入“建议使用的 skills”章节，列出接手代理应调用的 skills。

不要重复其他产物（规格、计划、ADR、issue、commit、diff）中已经记录的内容；改为通过路径或 URL 引用它们。

遮盖 API key、密码、个人身份信息等所有敏感内容。

如果用户传入了参数，把它们视为下一次会话重点的描述，并据此调整文档。
