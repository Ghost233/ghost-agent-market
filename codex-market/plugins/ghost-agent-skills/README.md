# Ghost Agent Skills Codex 插件

这个插件只包含不依赖 Owner、Goal 或 DAG 的普通 skill：

- \`git-commit\`：检查当前改动并按职责创建清晰的中文 Git 提交。
- \`git-merge-conflict\`：先考古两侧提交历史，再安全解决严重的 merge/rebase/cherry-pick 冲突。

推荐入口：

\`\`\`text
使用 $git-commit 检查当前改动，并按职责创建清晰的 Git 提交。
使用 $git-merge-conflict 考古两侧提交历史并解决当前严重的 Git 冲突。
\`\`\`
