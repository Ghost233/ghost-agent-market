# 镜像与数据

- 使用原生 `container image pull/push/load/save/tag/list/delete`，参数以当前 `--help` 为准。标准 OCI 镜像继续兼容服务器 Docker；归档格式和跨运行时加载以实际结果验证。
- 可复用的基础镜像归档保存在 `/Users/ghost233/dockerimage`。现有本地 Registry 数据在 `/Users/ghost233/dockerimage/registry`，宿主端口为 `127.0.0.1:15000`；与此 HTTP Registry 交互显式使用 `--scheme http`，不把这个选项用于公共 HTTPS 仓库。
- 镜像层留在原生运行时数据目录。指定业务数据的绑定目录不会移动镜像层；存储迁移另行授权和验证。
- 保留项目已有的公共 Base/业务镜像及标签策略；coinhub 的历史分层策略不扩展成其他项目的要求。
- 新镜像通过运行验收后，只精确清理已被替代、未被容器引用且有回滚副本或可重建的旧镜像。保留未使用的旧命名卷，直到其数据迁移和恢复验证完成；不以全局 prune 代替迁移清理。
- 含真实凭据的镜像只用于本地，不推到 Registry 或远端。远程构建和上传源码需要当前任务明确授权的端点。
- 归档恢复验证须校验哈希，并实际加载和运行。保护唯一副本、数据库目录和凭据；不通过自动删除数据来修复磁盘不足。
