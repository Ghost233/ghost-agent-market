# 杂项

我保留但很少使用的工具，不在插件中正式发布。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：配置 Claude Code hooks，在危险 Git 命令执行前拦截，例如 push、reset --hard 和 clean。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：将测试文件中的 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：创建包含章节、问题、解答和讲解的练习目录结构。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：配置 Husky pre-commit hooks，包含 lint-staged、Prettier、类型检查和测试。
