# RESOURCES.md 格式

`RESOURCES.md` 是为该主题精选的可信来源集合。讲解中的知识应取自这里，而不是模型参数中的猜测；智慧则来自这里列出的社群。

## 结构

```md
# {主题}资源

## 知识

- [Book: _The Science and Practice of Strength Training_ — Zatsiorsky & Kraemer](https://example.com)
  关于训练设计和适应的基础著作。用于：周期化、恢复、强度区间等内容。
- [Article: "How Much Should I Train?" — Greg Nuckols (Stronger By Science)](https://example.com)
  基于证据综述训练量基准。用于：各肌群每周组数目标。

## 智慧（社群）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信噪比 subreddit，严格管理缺乏依据的健身说法。用于：训练计划评议、平台期排查。
- 本地：{健身房名称}周二力量课程
  用于：获得动作的实时教练反馈。
```

## 规则

- **只收录高可信来源。** 优先选择一手来源、公认专家、同行评审成果和管理严格的社群。披着教育外衣的营销内容不要收录。
- **为每项资源添加说明。** 单独一个链接三个月后毫无用处。增加一行，说明它覆盖什么内容、何时应查阅。
- **按知识/智慧分组。** 与 [SKILL.md](./SKILL.md) 中的理念一致。资源只出现在其中一组也没有问题。
- **明确暴露缺口。** 如果使命需要的某个领域没有优质资源，创建 `## 缺口` 章节列出缺失内容，以推动后续搜索。
- **果断清理。** 被证明错误、浅薄或偏离使命的资源应当删除，而不是埋在列表里。五个精准来源胜过三十个平庸来源。
- **记录社群偏好。** 如果用户选择不加入社群，在此记录，避免未来会话反复建议。
