# 逻辑原型

构建一个独立完整的 HTML 文件，也就是任何人都能通过点击按钮驱动状态模型的**可分享演示**。当问题涉及**业务逻辑、状态转换或数据形状**时使用：这些设计纸面上看似合理，只有经过真实案例才会暴露不适之处。

因为只有一个文件且无需安装，可直接交给设计师、产品经理或领域专家等非开发者，让他们亲自体验模型。因此界面使用领域语言，而不是代码语言。

## 适用情形

- “我不确定这个状态机能否处理先 X 后 Y 的边缘情况。”
- “这个数据模型真的能表示……这种情况吗？”
- “我想在编写 API 前先体验它应该是什么样。”
- 任何希望**按下按钮并观察状态变化**的情形。

如果问题是“它应该长什么样”，说明分支选错了；改用 [UI.md](UI.md)。

## 流程

### 1. 明确问题

写代码前，用一个段落说明正在为哪个状态模型、哪个问题制作原型。把它作为可见介绍放在演示顶部，而不只是代码注释。回答错误问题的逻辑原型毫无价值；明确问题，使用户无论现在参与还是稍后回来都能核对。

### 2. 将逻辑隔离为可移植模块

把真正回答问题的逻辑放进一个 `<script>` 块，写成小型纯模块，以后可以直接取出并放入真实代码库。周边页面是一次性的，这个模块不是。

合适的形态取决于问题：

- **纯 reducer**：`(state, action) => state`。适用于动作是离散事件、状态是单个值的情况。
- **状态机**：显式状态和转换。适用于问题包含“当前哪些动作合法”的情况。
- **作用于普通数据类型的一小组纯函数**：适用于没有隐含当前状态、只有转换的情况。
- **具有清晰方法表面的类或模块**：适用于逻辑确实拥有持续内部状态的情况。

选择最符合问题的形态，*不要*选择最容易接到页面上的形态。保持纯粹：不使用 DOM、`document`，按钮处理器也不进入内部。页面调用模块，模块不反向依赖页面。这样原型才会在生命周期结束后继续有价值：问题得到答案后，已验证的 reducer、状态机或函数集可独立迁入真实模块。

### 3. 构建可分享 HTML

只使用一个普通 HTML/CSS/JS 文件，不使用框架、bundler 或服务器。全部内容内联，确保双击即可打开，也能通过邮件转发，任何人打开文件都能运行。

面向非开发者编写。所有标签使用**领域语言**而非代码语言；按钮和状态读起来应像业务，而不是 reducer。用平实语言解释正在发生什么。

按从上到下的清晰层级布局：

1. **标题与单行说明**：说明此演示可探索什么，即步骤 1 中的问题。
2. **当前状态**：以可读面板渲染全部相关状态，使用带标签字段而非原始 JSON。每次点击后重新渲染，让变化可见；必要时指出刚刚发生的变化，帮助非开发者理解。
3. **自由操作按钮**：每个动作一个按钮，始终可用，任何人都能按任意顺序探索模型。每次点击派发动作并重新渲染状态。
4. **引导流程**：每个标签页对应一个**场景**。标签页用简短平实语言说明场景设置和观察重点，下方按顺序放置该场景需要点击的**按钮**。每一步都是真实按钮，点击会执行动作并进入下一步。开始引导流程时重置到已知初始状态，保证场景每次运行一致。

选择能展示棘手情形的场景：正常路径、复杂边缘情况、尝试不应合法的操作，以及其他纸面上难以推理的案例。

保持美观但克制：整洁排版、充足间距、单一强调色。不使用动画和噱头，不让任何元素与状态和按钮争夺注意力。

### 4. 交给用户

发送文件或为用户打开。用户可以在方便时体验引导流程和自由操作。最有价值的时刻是他们说“等等，这不应该发生”或“原来 X 和我想的不一样”；这暴露的是_想法_中的缺陷，正是原型的目的。用户需要新动作或新场景时就添加，原型会演进。

### 5. 留存答案与原型

原型回答问题后，先记录答案，再按 [SKILL](SKILL.md) 所述保存原型。逻辑分支的对应方式是：把已验证的 reducer、状态机或函数集迁入真实模块（吸收决策）；HTML 外壳则进入一次性分支，作为一手来源保留。它是独立单文件，因此在那里仍可轻松重新运行。

## 反模式

- **不要添加测试。** 需要测试的原型已不再是原型。
- **不要连接真实数据库。** 除非问题明确涉及持久化，否则使用内存状态。
- **不要泛化。** 不考虑“以后如果支持 X”。原型只回答一个问题。
- **不要混合逻辑与页面。** 纯模块一旦引用 DOM、`document` 或按钮处理器，就无法迁移。让页面只是纯模块外的一层薄壳。
- **不要使用框架、bundler 或服务器。** 接收者应双击一个文件即可运行；React 应用或开发服务器会破坏“可分享”目标。
- **不要把 HTML 外壳发布到生产。** 页面针对人工点击体验优化，真正值得保留的是背后的逻辑模块。
