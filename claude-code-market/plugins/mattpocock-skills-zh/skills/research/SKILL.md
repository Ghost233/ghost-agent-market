---
name: research
description: 对照高可信一手来源调研问题，并将发现保存为仓库中的 Markdown 文件。适用于用户希望调研某个主题、收集文档或 API 事实，或把资料阅读工作委托给后台代理时。
---

启动一个**后台代理**执行调研，以便它阅读资料时你仍可继续其他工作。

它的任务是：

1. 对照**一手来源**调查问题，包括官方文档、源代码、规范和第一方 API，不依赖转述这些内容的二手文章。把每一项主张追溯到拥有该信息的原始来源。
2. 将发现写入一个 Markdown 文件，并为每一项主张标注来源。
3. 把文件保存到仓库现有的同类笔记位置，并遵循已有约定；如果没有约定，则选择合理位置，并说明保存在哪里。
